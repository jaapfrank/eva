# Contributing to Eva2

Work from the repository root on a codex/ branch. Read AGENTS.md, PROJECTDOEL.md,
ARCHITECTUUR.md and the current workboard before editing. Keep new code, identifiers
and technical documentation in English; user-facing language follows the household.

Use the existing application ports and provider contributions. Do not add a second
planner, memory store, tool execution route or example-specific core behavior.
Optional integrations stay outside the provider-neutral core. Reuse locked dependencies.

Verify the actual affected route with focused existing checks and an independent review.
Use disposable test data, never live private databases. Do not publish credentials,
private conversations, assessment cases or local captures. Preserve old proof bytes.
Update the machine-readable workboard and render WERKBORD.md on actual state changes.

The project license has not been changed by this reorganization.
