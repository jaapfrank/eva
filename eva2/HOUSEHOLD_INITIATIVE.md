# Household initiative delivery

The existing sensory decision worker now supports household-only context. A separate durable namespace retains the household, device and policy binding from admission through the announcement receipt. Private sensory expressions remain on their existing Telegram route.

Runtime composition uses an existing open native household work session to select one recent speaker. This indicates a destination, not a recognized person or proof of current presence. Session closure/expiry, the initiative mandate and household authority remain effective stop boundaries. Home Assistant must report the satellite idle immediately before announcement.

Initial installation defaults: Europe/Amsterdam, quiet from 22:00 to 08:00, at most two offered announcements per local day, one review per hour across the installation. Pending expressions expire after fifteen minutes. Empty shared memory produces silence without a model call. Reviews use the existing reflection and model admission budgets; no new spending allowance is added.

A successful HA service response is recorded as **offered**, never heard. Interrupted attempts finish without replay; ambiguous outcomes remain needs-help. Production receipts use the exact prepared message and bound destination. Private memory, private task history and private initiative proposals are excluded from household generation.

Installation startup checks do not prove audible delivery, usefulness, naturalness or end-to-end performance. Those remain part of the deferred physical and family trials. This connects shared-context presence; it does not implement person recognition or automatically route private initiative results to speakers.
