# MCP wire-types-only comparison

Deze map is de kleine helft van de vergelijking in
`../mcp-sdk-v1/README.md`. De volledige, hashgebonden kandidaatlock voegt alleen
`mcp-types==2.1.1` toe aan Eva's ongewijzigde 38 productiepackages.

Een tijdelijke integratie werkte, maar maakte de productcode netto 87 regels
groter omdat Eva haar begrensde HTTP/SSE-transport toch moest behouden. Daarom
is dit reproduceerbaar beslisbewijs, geen runtime- of releaseauthority.
